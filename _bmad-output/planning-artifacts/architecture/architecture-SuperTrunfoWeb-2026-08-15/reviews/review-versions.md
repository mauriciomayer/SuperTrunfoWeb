# Stack Version Review — ARCHITECTURE-SPINE.md

Fact-checked live against the web on 2026-08-15.

- **Node.js 24 LTS** — CONFIRMED. Node 24 is the current active LTS line as of mid-2026 (LTS support through ~April 2028); Node 26 shipped April 2026 as a short-lived/non-LTS-track major under the old schedule. Reasonable to start a new project on. Source: [Node.js — Evolving the Node.js Release Schedule](https://nodejs.org/en/blog/announcements/evolving-the-nodejs-release-schedule), [Node.js 24 Becomes LTS](https://nodesource.com/blog/nodejs-24-becomes-lts).

- **TypeScript 5.7+** — CONFIRMED BUT STALE/IMPRECISE. TypeScript 5.7+ exists and is technically satisfied by any later version, but the spine understates the state of the world: TypeScript 6.0 (the last JS-based release) shipped March 2026, and **TypeScript 7.0 (the Go-native compiler rewrite, ~8-12x faster) reached General Availability on July 8, 2026** — over a month before this document's date. Pinning to "5.7+" for a new project starting today reads as if it wasn't checked against the current landscape; it should at minimum discuss 7.0's native compiler and its tooling/plugin-ecosystem implications. Source: [TypeScript 6.0 announcement](https://devblogs.microsoft.com/typescript/announcing-typescript-6-0/), [TypeScript 7.0 GA coverage](https://www.digitalapplied.com/blog/typescript-7-0-ga-native-compiler-migration-playbook-2026), [TypeScript 7.0 RC](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0-rc/).

- **Colyseus (servidor) 0.17.x** — CONFIRMED. This is the current server line; latest packages are around `@colyseus/core@0.17.50` / `colyseus@0.17.10`, and 0.18 has not shipped yet (per the maintainer, 0.18 is planned as the last release before 1.0). Reasonable pin for a new project today. Source: [Colyseus 0.17 is here!](https://colyseus.io/blog/colyseus-017-is-here/), [colyseus/colyseus releases](https://github.com/colyseus/colyseus/releases), [Endel (maintainer) on 0.18 roadmap](https://x.com/endel/status/2054957224171069494).

- **colyseus.js (SDK cliente) 0.17.x "pareada com o servidor"** — **OUTDATED / FACTUALLY WRONG.** The `colyseus.js` npm package is stuck at **0.16.22** and was **not** updated for the 0.17 line. The official Colyseus 0.17 migration guide explicitly says the client package was renamed/replaced: *"In the front-end, replace `colyseus.js` with the `@colyseus/sdk` package"* — client apps pairing with a 0.17.x server should install `@colyseus/sdk` (currently ~0.17.42), not `colyseus.js`. This is exactly the kind of claim that looks like it came from training-data memory (colyseus.js was the historically correct package name in older Colyseus versions) rather than a live check — there is no `colyseus.js@0.17.x` to pin to. **This needs a correction in the spine and in the Structural Seed's `frontend/src/client/` comment.** Source: [Colyseus 0.17 migration guide](https://docs.colyseus.io/migrating/0.17), [@colyseus/sdk on npmx](https://npmx.dev/package/@colyseus/sdk), [colyseus.js on npm](https://www.npmjs.com/package/colyseus.js).

- **React 19.2.x** — CONFIRMED. React 19.2 shipped October 2025 and is the current minor line as of August 2026 (latest patch ~19.2.8, July 2026); no React 19.3 or React 20 has been announced/released. Reasonable pin. Source: [React 19.2 blog post](https://react.dev/blog/2025/10/01/react-19-2), [React versions](https://react.dev/versions), [React 19.2.8 release](https://github.com/react/react/releases/tag/v19.2.8).

- **Vite 8.x** — CONFIRMED, and compatible with the stated Node version. Vite 8.0 is released and current; it requires Node.js 20.19+ or 22.12+ (same floor as Vite 7), which Node 24 LTS satisfies comfortably. No conflict with React 19.2.x either (standard `@vitejs/plugin-react` support). Source: [Vite 8.0 is out!](https://vite.dev/blog/announcing-vite8), [Vite Releases](https://vite.dev/releases).

## Compatibility notes
- Node 24 / TypeScript / React 19.2 / Vite 8 all check out as mutually compatible — no version-floor conflicts found.
- Colyseus server 0.17.x and the stated client SDK are **not actually paired**: `colyseus.js` never reached 0.17, so "colyseus.js 0.17.x (pareada com o servidor)" describes a package/version combination that does not exist on npm. The correct pairing is server `colyseus`/`@colyseus/core@0.17.x` with client `@colyseus/sdk@0.17.x`.

## Overall verdict
Five of six stack entries check out as current and mutually compatible as of August 2026, but the client SDK line is a real, checkable error — the spine names a package (`colyseus.js`) that was never released at version 0.17.x and has in fact been superseded/renamed to `@colyseus/sdk` for that server line, so this entry must be corrected before implementation starts.
